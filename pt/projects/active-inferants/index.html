Os "Active Inferantes" é um projeto de modelagem multiagente que aplica a Inferência Ativa ao comportamento coletivo, inspirado na dinâmica das colônias de formigas. Ele produziu um repositório GitHub, um artigo de 2021 e código desenvolvido dentro do projeto Active Blockference, com múltiplas realizações em diferentes contextos de modelagem.

Visão Geral

Os "Active Inferantes" desenvolvem modelos de múltiplos agentes utilizando a Inferência Ativa para simular e compreender comportamentos coletivos. O projeto se inspira na biologia das insetos sociais, particularmente na busca e organização de colônias de formigas, e aplica modelagem gerativa para entender como os comportamentos locais dos agentes produzem inteligência coletiva sem coordenação central.

Trabalho Anterior e Artigos

O artigo fundamental do projeto é Friedman, Tschantz, Ramstead, Friston e Constant (2021), "Um Framework de Inferência Ativa para o Comportamento das Colônias de Formigas", publicado na Frontiers in Behavioral Neuroscience — entre os primeiros artigos de Inferência Ativa a modelar a comunicação estigmergica (mediada por feromônios). O projeto também mantém um repositório do GitHub com múltiplas realizações de código e é desenvolvido em parte através do projeto Active Blockference. O trabalho abrange modelos de agentes individuais, cenários de coleta coletiva e extensões teóricas.

Participe

Contribuidores com formação em biologia computacional, sistemas multiagente, Inferência Ativa ou ecologia comportamental são bem-vindos. Contribuições técnicas (código, modelos) e trabalhos conceituais (teoria, documentação) são ambos valorizados.
