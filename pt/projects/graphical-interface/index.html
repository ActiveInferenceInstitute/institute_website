O projeto de Interface Gráfica desenvolve ferramentas visuais e interativas para trabalhar com modelos de Inferência Ativa. Ele se concentra em tornar a estrutura, dinâmica e saídas dos modelos mais acessíveis através de interfaces gráficas e camadas de visualização bem projetadas.

Visão Geral

O projeto da Interface Gráfica cria ferramentas para o usuário que exploram, constroem e visualizam modelos de Active Inference. Boas interfaces visuais reduzem a barreira de entrada para trabalhar com modelos generativos e tornam a estrutura do modelo mais interpretável para praticantes e pesquisadores. Seu objetivo fundador foi uma interface gráfica acessível para um grafo de conhecimento extensível para aprendizado e aplicação de Active Inference, conectando os textos dos modelos e referências em uma estrutura navegável e interligada.
