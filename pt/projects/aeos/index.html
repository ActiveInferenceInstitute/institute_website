Ontologia de Entidades Ativas para Ciência (EAOS)

Um arcabouço que aplica o Active Inference para modelar a atividade científica como um processo cognitivo coletivo.

Liderar: Daniel Friedman

📦 Este projeto está arquivado. Não está mais ativo e qualquer participação abaixo descreve como ele operava anteriormente.

AEOS repositoryZenodo publication

AONT se (AEOS) é um projeto do Instituto de 2022 que aplica os princípios da Inferência Ativa para modelar a atividade científica como um processo cognitivo coletivo. Fornece um framework composável e versionável para entender tanto a ciência institucional tradicional quanto as abordagens DeSci descentralizadas, integrando uma perspectiva BOLTS (Negócios, Operações, Legais, Técnicas, Sociais) para análise abrangente.

Visão Geral

AEOS uses Active Inference to model scientific activity as a collective cognitive process situated within a niche. It maps relationships between scientific entities and processes through Active Inference entity partitioning, and applies to both institutional science and decentralized science.

The framework aims to support the emergence of epistemic communities, transparent resource allocation and knowledge sharing, and tools for decentralized scientific governance.

Publicação

O framework é publicado como “Uma Ontologia de Inferência Ativa para a Ciência Descentralizada: da Construção Situada do Sentido ao Comum Epistêmico” (Friedman, Applegate-Swanson, Balbuena, Choudhury, Cordes, El Damaty, Guénin-Carlut, Knight, Metelkin, Shrivastava, Singh, Smékal, Tuttle e Vyatkin, 2022), arquivado abertamente no Zenodo.

Participe

As contribuições incluem estender a ontologia para novos domínios, aplicar o framework a ferramentas de ciência descentralizadas e pesquisar fluxos de trabalho multiagente que se baseiam no AEOS. Experiência em Active Inference, engenharia de ontologias ou ciência descentralizada é útil.
