CogNarr (Narrativa Cognitiva) é um projeto de ecossistema que desenvolve infraestrutura para facilitar a cognição em grupo em larga escala. Ele cria ferramentas e estruturas que permitem que comunidades coordenem uma compreensão compartilhada através de narrativa estruturada e apoio cognitivo, com foco inicial no incubador viável mínimo.

Visão Geral

CogNarr desenvolve infraestrutura para o senso comum coletivo — criando andaimes cognitivos compartilhados que ajudam grupos a coordenar atenção, atualizar crenças e manter ações coerentes. A missão inicial é uma plataforma de incubação mínima viável que pode servir como camada de coordenação para a cognição comunitária. O projeto é liderado por John Boik, Pesquisador Associado no Institute, e continua ideias de seu trabalho anterior sobre arquiteturas cognitivas em escala social, incluindo Economia Direta Democrática.

Financiamento

CogNarr está atualmente sem financiamento. Doações para o Instituto de Inferência Ativa destinadas ao projeto CogNarr ajudam a apoiar o seu desenvolvimento; o projeto é concebido como de código aberto, com espaço para parceiros de desenvolvimento e investidores sociais.

Reuniões e Atividades

O CogNarr realiza reuniões de projeto regulares visíveis no calendário de atividades do Instituto. O projeto possui uma comunidade ativa no Discord.
