Agente de Inferência Ativa para Modelagem da Tradução Humana

Modelando processos de tradução humana utilizando arquiteturas de agentes de Inferência Ativa.

Lead: Michael Carl

📦 Este projeto está arquivado. Não está mais ativo e qualquer participação abaixo descreve como ele operava anteriormente.

GitHubEcosystem

Este projeto de Ecossistema desenvolve um modelo de agente de Inferência Ativa dos processos de tradução humana. Ele aplica o framework de energia livre às tarefas cognitivas e linguísticas envolvidas na tradução entre idiomas, produzindo modelos do comportamento de tradução humana.

Visão Geral

Utilizando o Active Inference como um arcabouço de modelagem, o projeto modela a tradução como um problema de inferência — onde o tradutor minimiza o erro de previsão sobre as representações da língua alvo dadas as entradas da língua original. O trabalho inclui desenvolvimento teórico e implementações de agentes, conectando-se ao campo da Pesquisa do Processo de Tradução.
