START

A modular pipeline that generates professional-domain educational materials on Active Inference and the Free Energy Principle.

Lead: Daniel Friedman

GitHub repositoryDocumentation

START is a modular content-generation pipeline that produces high-quality educational materials on Active Inference and the Free Energy Principle, tailored to professional domains and individual learners. It integrates live web research via Perplexity and large language models via OpenRouter to produce evidence-based, professionally-contextualized learning content.

Overview

START combines live web research and large language models to generate learning materials that connect Active Inference and the Free Energy Principle to a learner's own professional domain, rather than relying on a single generic curriculum. The pipeline is open source and multilingual, aimed at making Active Inference concepts accessible across fields and languages.
