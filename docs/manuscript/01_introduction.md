# Introduction

Research resources are difficult to reuse when citations decay. A content editor should be able to reorganise the source tree without changing a resource's public URL. This requirement is stronger for localized pages because a rename can affect the default locale, translation entrances and references from other sites.

The site treats routing as a content property. This study describes the repository's source contract and the classes of verification a maintainer can use before changing public URLs. Its scope is the build architecture. Search ranking, audience engagement and observed uptime require different evidence.
