시작은 모듈러 콘텐츠 생성 파이프라인으로, {title}와 자유 에너지 원칙에 대한 품질 높은 교육 자료를 프로페셔널 분야와 개인 학습자 맞춤형으로 생산합니다. 이를 위해 Perplexity에서 실시간 웹 연구와 OpenRouter에서 대형 언어 모델을 통합하여 근거가 있는, 전문적으로 맥락화된 학습 콘텐츠를 생성합니다.

개요

START는 실시간 웹 연구와 대형 언어 모델을 활용하여 학습 자료를 생성합니다 이 자료는 연결된 프레임워크인 활성 인퍼전과 자유 에너지 원칙에 사용자 자신의 전문 분야가 결합됩니다. 과정은 오픈 소스이며 다국어화되어 있어 다양한 field와 언어 간에 활성 인퍼전 개념을 접근할 수 있도록 합니다.
