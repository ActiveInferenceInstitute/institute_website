Active Blockference는 분산형 및 블록체인 관련 시스템에 적용 가능한 액티브 인퍼런스 예제와 도구를 개발합니다. 이 프로젝트는 GitHub 저장소, 블로그 게시물, 비디오 개요를 제작했으며, 액티브 인퍼런트(Active InferAnts)의 다중 에이전트 모델링 작업 통합 허브 역할을 합니다.

개요

Active Inference Institute는 분산 환경에서 Active Inference을 적용하는 방법을 탐구합니다. 이 프로젝트는 블록체인과 분산 시스템 맥락에서 생성 모델과 자유 에너지 최소화가 어떻게 적용되는지 보여주는 모델링 예제, 구현 및 자원을 개발합니다.

과거 작업 및 자원

Active Inference Institute는 GitHub 저장소에 구현 및 예시를 제공하고, 개념적 프레임워크를 설명하는 블로그 게시물과 프로젝트 회의 동영상을 제작했습니다. Active Inference의 다중 에이전트 작업은 Active Blockference 내에서 부분적으로 개발되었습니다.
