Active Inference Institute 提议建立开放的社区工作组体系：一个负责整个领域比较及共同评估方法的全领域工作组，以及将主动推理专家与领域实践者相结合的应用领域工作组。章程和操作程序草案现已在 GitHub 上开放公开审阅。拟在第六届 Applied Active Inference Symposium 的章程制定会议上创立这些工作组；研讨会将于 2026 年 11 月 12–13 日在线举行。

工作组是什么

工作组是围绕明确工作目标成立的有限职责组织，依据书面章程实行透明治理，产出供整个领域使用或舍弃的公开成果。工作组由其成员组建。成员对工作组成果中的技术分析、解释和结论负责。

研究院承担行政职责，而不承担知识裁决职责：召集工作组，提供不参与投票的联络员，并作为其成果唯一的官方出版机构。出版审查仅涉及机构政策、机构表述的准确性和许可条款。研究院不得解散工作组；研究院退出召集角色后，工作组仍可继续存在。

这一提议载于立场文件《协调整个领域：Active Inference 生态系统层面的技术路线规划与社区工作组的理由》（Active Inference Institute Working Paper Series，版本 1.0.0，2026 年 9 月；DOI 10.5281/zenodo.23066904）。

全领域工作组

全领域工作组负责整个领域的可比性和共同评估方法。拟议的首年成果如下：

  1. 为一组明确定义的核心术语建立对应矩阵，至少覆盖 SPM/DEM、pymdp 和 RxInfer.jl 中的用法。
  2. 针对少量标准问题制定公开比较协议，区分概念、算法和数值层面的对应关系，固定版本，明确等价规则，并至少提供一个跨两个实现的完整示例。
  3. 与已组建的领域工作组共同审阅并商定一个共享的领域评估框架。
  4. 由至少两名既非研究院董事会成员、也非起草者的外部评审人审阅矩阵和协议。

至少五人书面承诺承担这一工作目标时，全领域工作组即可组建；其中至少一人须维护或实际使用初始比较集合中的某个实现。欢迎 SPM、pymdp、RxInfer.jl 或其他实现的开发者和使用者加入。

应用领域工作组

每个应用领域工作组聚焦一个应用领域：能否按照该领域自身的概念引入 Active Inference，以及依据共同评价标准，该领域目前处于什么阶段。拟议的首年成果包括：受众与用例说明；由主动推理专家和领域实践者共同设计的一个基础知识或适配模块；参加全领域工作组的框架系列活动，并提交初步领域评估；以及公开作出关于工作组是否继续运作的决定。

至少五人书面承诺完成首年成果时，领域工作组即可组建；其中必须至少包括一名主动推理专家和一名正在该领域工作的实践者。Scientific Advisory Board 成员可自愿承担专家角色。领域工作组数量不设上限。

论文建议的候选领域如下：

  • 医疗保健和临床医学
  • 神经科学
  • 心理健康和精神医学
  • 教育和学习科学
  • 人工智能和 AGI
  • 机器人、无人机和自主系统
  • 金融和经济决策
  • 气候与环境科学
  • 网络安全
  • 物流

国防和国家安全应用不纳入试点首年，须待适当的伦理审查程序建立后再考虑。

本网站的 Active Inference and X 页面汇集了多个领域的现有资源。它们并非已组建的工作组；领域工作组只有满足上述条件后才成立。

共同评估框架

论文提出一个七阶段的领域发展框架，作为暂定的启发式方法，使每个领域工作组均可按照相同标准进行自我评估：

  1. 理论认知
  2. 向应用领域转化
  3. 社区形成
  4. 教育基础设施
  5. 资格认证和实践者市场
  6. 标准、审查和专业活动
  7. 机构成熟度

研讨会可暂行采纳这一框架作为起始文本。随后，全领域工作组与已组建的领域工作组共同审阅、完善并商定各领域使用的版本。阶段评级仍属于各领域工作组自身的分析。

创立时间表

现在至 2026 年 11 月。 在 GitHub 上公开审阅章程和操作程序草案。

第一阶段：研讨会期间（2026 年 11 月 12–13 日）。 暂行采用章程和操作程序，进入为期 90 天的正式批准期；组建全领域工作组，以及所有未被延期且达到最低组建门槛和参与条件的领域工作组；选举临时主席和副主席；制定第二阶段的 90 天日程；暂行采用七阶段框架作为起始文本。

第二阶段：90 天内。 由全体活跃成员合计的三分之二特别多数正式批准最终章程和操作程序；确认框架起始文本；制定首年工作计划；依据正式批准的章程选举负责人。

首年结束后。 开展为期十二个月的试点评估，并适用停止规则：未完成指定首年成果的工作组暂停运作。随后对整个体系开展五年期存续审查，最迟于 2031 年 11 月完成。

如何参与

  • 参加章程制定会议。 所有已注册的研讨会参与者均可参加，并可远程参与和远程参加所有实质性投票。参会并不意味着必须加入工作组。
  • 在 GitHub 上审阅并提出意见。 在 Working_Groups 仓库中提交议题，说明文档名称和章节、您的疑虑，以及能够解决问题的修改建议。
  • 通过电子邮件提出意见。 写信至 blanket@activeinference.institute，邮件主题为 [WORKING GROUPS]。
  • 表达加入工作组的意愿。 提交议题，说明全领域工作组或某个应用领域，以及您可以承担的角色：主动推理专家、领域实践者、实现的维护者或使用者。

任何具有相关专业知识或实质性兴趣的人都可以加入，包括 Active Inference 的批评者以及并不支持该框架的领域实践者。加入无需付费，也无需成为研究院会员。活跃成员应参加每年四次、每次约九十分钟的季度会议，并为至少一项首年成果作出贡献。所有会议均远程举行。

問答

常见问题

摘自立场文件和章程草案的简要回答。

加入是否需要具备 Active Inference 专家资格？

不需要。任何具有相关专业知识或实质性兴趣的人均可加入，并不局限于掌握相关数学的人。领域工作组既需要领域实践者，也需要主动推理专家。

加入需要付费吗？

不需要。加入无需提供资金，也无需成为研究院会员。向研究院捐款并不是加入、发言或参与的条件。

研究院负责哪些决定？

行政事务包括召集、联络员、机构政策，以及仅限于机构表述和许可条款的出版审查。技术和科学内容由工作组负责。采纳某项成果确立的是工作组的立场，并不代表整个领域的科学共识。

工作组未完成成果时会怎样？

根据拟议的停止规则，未完成指定首年成果的工作组将暂停运作，研究院也将暂停为其提供协调支持和出版服务。研究院不得解散工作组；工作组可自行解散。
