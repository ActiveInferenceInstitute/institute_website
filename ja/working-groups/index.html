Active Inference Institute は開かれたコミュニティ作業部会の制度を提案しています。分野全体での比較と共通の評価方法を扱う一つの部会と、能動推論の専門家と領域の実務家を組み合わせる応用領域の部会からなります。章程と運営手順の草案は現在 GitHub で公開検討されています。部会の設立は、2026 年 11 月 12–13 日にオンライン開催される第6回 Applied Active Inference Symposium の章程策定セッションで提案されています。

作業部会とは

作業部会は明示された作業目的を担う、責任範囲を限定した組織です。書面の章程と透明なガバナンスのもとで活動し、分野の人々が利用または採用しないことを選べる公開成果を生み出します。部会は会員によって設立されます。成果の技術的分析、解釈、結論に対する責任は会員にあります。

研究院の役割は運営上のものであり、知見の判断を担うものではありません。部会を招集し、投票権のない連絡担当者を置き、成果の唯一の公式出版主体となります。出版審査は機関方針、機関に関する表明の正確性、ライセンス条件に限られます。研究院は作業部会を解散してはならず、招集者を退いても部会は存続します。

提案はポジションペーパー『分野の調整：Active Inference におけるエコシステム規模の技術ロードマッピングとコミュニティ作業部会を設ける理由』（Active Inference Institute Working Paper Series、バージョン 1.0.0、2026 年 9 月、DOI 10.5281/zenodo.23066904）に記載されています。

分野全体の作業部会

分野全体の作業部会は、分野全体での比較可能性と共通の評価方法を扱います。提案された初年度成果は次のとおりです。

  1. 少なくとも SPM/DEM、pymdp、RxInfer.jl で用いられる、明確に定めた中核用語の対応表。
  2. 少数の標準問題に対する公開比較手順。概念、アルゴリズム、数値の対応を区別し、バージョンを固定し、等価性の規則を明記し、少なくとも一つの例を二つの実装で示します。
  3. 設立済みの領域部会と検討し、合意した共通の領域評価枠組み。
  4. 研究院の理事でも起草者でもない、少なくとも二人による対応表と手順の外部審査。

少なくとも五人がこの作業目的への取り組みを書面で約束した時点で、分野全体の部会が設立されます。その中には、初期比較集合の実装を保守または実際に利用する人が少なくとも一人必要です。SPM、pymdp、RxInfer.jl または他の実装の開発者と利用者を歓迎します。

応用領域の作業部会

各応用領域の作業部会は一つの応用領域を扱い、その領域自身の概念で Active Inference を導入できるか、共通の基準で現在どの段階にあるかを検討します。提案されている初年度成果は、対象者とユースケースの説明、能動推論の専門家と領域の実務家が共同設計する基礎理解または適応のための一つのモジュール、分野全体の部会による枠組みシリーズへの参加と初期領域評価、そして部会の継続の可否に関する公開の判断です。

少なくとも五人が初年度成果への取り組みを書面で約束した時点で、領域部会が設立されます。その中には、少なくとも一人の能動推論の専門家と、その領域で実際に活動する少なくとも一人の実務家が必要です。Scientific Advisory Board の会員は、専門家役を自発的に担うことができます。領域部会の数に上限はありません。

論文が提案する候補領域は以下のとおりです。

  • 医療と臨床医学
  • 神経科学
  • メンタルヘルスと精神医学
  • 教育と学習科学
  • 人工知能と AGI
  • ロボティクス、ドローン、自律システム
  • 金融と経済的意思決定
  • 気候と環境科学
  • サイバーセキュリティ
  • 物流

国防と国家安全保障への応用は試行の初年度では延期し、適切な倫理審査手続きの整備を待ちます。

本サイトの Active Inference and X ページは、多くの領域の既存資料を集めています。これらは設立済みの作業部会ではありません。領域部会は、上記の条件を満たして初めて成立します。

共通の評価枠組み

論文は、各領域部会が同じ基準で自己評価できるよう、暫定的な指針として七段階の領域発展枠組みを提案しています。

  1. 理論的理解
  2. 応用領域への転換
  3. コミュニティ形成
  4. 教育基盤
  5. 資格認定と実務家市場
  6. 標準、審査、専門イベント
  7. 組織としての成熟

シンポジウムは、この枠組みを出発点の文案として暫定採用できます。その後、分野全体の作業部会と設立済みの領域部会が検討、改善を行い、各領域で使う版に合意します。段階の評価は各領域部会自身の分析です。

設立日程

現在から 2026 年 11 月まで。 GitHub で章程と運営手順の草案を公開検討します。

第1段階：シンポジウム期間中（2026 年 11 月 12–13 日）。 章程と運営手順を暫定採用し、90 日間の正式批准期間に入ります。分野全体の作業部会と、延期対象ではなく設立の最低条件と参加条件を満たす全領域の部会を設立します。暫定議長と副議長を選出し、第2段階の90日間の日程を定め、七段階の枠組みを出発点の文案として暫定採用します。

第2段階：90 日以内。 全部会の活動中の会員を合わせた三分の二の特別多数で、最終章程と運営手順を批准します。枠組みの出発点となる文案を確認し、初年度作業計画を定め、批准済み章程に従って役員を選出します。

初年度終了後。 十二か月の試行評価を行い、指定された初年度成果を完成していない部会は停止するという規則を適用します。その後、制度全体について五年目の存続見直しを行い、遅くとも 2031 年 11 月までに実施します。

設立文書

章程草案（ポジションペーパーの付録 A）と運営手順（付録 B）は、継続的に更新する文書として Working_Groups リポジトリで維持されています。参照した先行のガバナンス文書である IEEE Technical Committees、IETF の作業部会プロセス（RFC 2418）、W3C Process Document、IRS Form 1023 の利益相反方針例、ANSI Essential Requirements も併せて収録されています。各文書の脚注は、各規定の先行資料または設計理由を示しています。

ポジションペーパーは、公開時の付録とともに Zenodo に保存されています。その後の変更はリポジトリ版に反映されます。

参加方法

  • 章程策定セッションに参加する。 登録済みのシンポジウム参加者全員に開かれており、遠隔参加と、すべての実質的な採決への遠隔アクセスが可能です。参加しても作業部会に加入する義務はありません。
  • GitHub で確認し、意見を提出する。 Working_Groups リポジトリで、文書名と節、懸念点、それを解消する変更案を記載した Issue を作成してください。
  • メールで意見を提出する。 件名を [WORKING GROUPS] として blanket@activeinference.institute に送信してください。
  • 部会への参加意向を示す。 分野全体の作業部会または応用領域と、担当できる役割（能動推論の専門家、領域の実務家、実装の保守担当者または利用者）を明記した Issue を作成してください。

関連する専門知識または実質的な関心を持つ誰もが加入できます。Active Inference の批判者や、この枠組みを支持しない領域の実務家も含まれます。会費も研究院への入会も不要です。活動中の会員には、年四回、各約九十分の四半期会議への参加と、少なくとも一つの初年度成果への貢献が期待されます。会議はすべて遠隔で行います。

質問と回答

よくある質問

ポジションペーパーと章程草案に基づく簡潔な回答。

加入には Active Inference の専門家である必要がありますか？

いいえ。関連する専門知識または実質的な関心を持つ誰もが加入でき、基礎となる数学を扱える人だけに限定されません。領域部会には、能動推論の専門家と同じく領域の実務家が必要です。

加入に費用はかかりますか？

いいえ。加入には金銭的な貢献も研究院への入会も必要ありません。研究院への寄付は、加入、発言、参加の条件ではありません。

研究院は何を決定しますか？

運営事項には、招集、連絡担当者、機関方針、機関に関する表明とライセンス条件に限った出版審査が含まれます。技術的・科学的内容は作業部会の責任です。成果の採用は作業部会の立場を確立するものであり、分野全体の科学的合意を示すものではありません。

部会が成果を出さない場合はどうなりますか？

提案された停止規則では、指定された初年度成果を完成していない部会は停止し、研究院もその部会への調整支援と出版を停止します。研究院は部会を解散してはなりません。部会は自ら解散できます。
