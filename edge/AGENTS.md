# Edge adapter guidance

This is a prepared deployment option, not an active network boundary. Preserve
the single generated redirect map and fail on unsafe or chained mappings. Never
bind all subdomains, proxy back through the custom-domain Pages URL, upload the
source checkout, or change DNS/zone ownership as part of a local build.

Network and account changes require the concrete binding plan in
[README.md](README.md) and separate authorization. Tests must distinguish pure
Fetch behavior from a live provider deployment.
